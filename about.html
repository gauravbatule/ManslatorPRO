About Manslator Pro

An AI-powered translator that decodes the subtext behind what she said — and arms you with the perfect, confident reply.

💡 What is Manslator Pro?

Manslator Pro is a witty, AI-driven web app that helps you decode the hidden meaning behind what someone says — and instantly suggests a sharp, confident, perfectly-calibrated reply.

Whether she's being playful, emotional, testing you, or just looking for the right reaction, Manslator translates the subtext so you always know what's really going on — and exactly what to say.

Powered by Groq's ultra-fast inference API and a Llama 3 family model, responses are fluent in Hinglish (a natural Hindi-English blend) so the replies feel authentic, not robotic.

✨ Features

🧠 Smart Translation AI decodes the hidden emotion and subtext behind any message, no matter how subtle.
💬 Witty Replies Generates a short, confident, punchy comeback that perfectly matches the vibe.
🌙 Dark Mode UI Cinematic glassmorphism design with a deep dark palette and smooth animations.
🍔 Quick Prompt Menu Hamburger playbook with witty presets — and save your own custom prompts for quick reuse.
📱 Mobile Friendly Fully responsive layout that works beautifully on any screen size, including phones.
⚡ Keyboard Shortcut Press Ctrl + Enter to instantly fire off a translation without touching the mouse.
🛡️ Input Validation Character limit (500), empty-state checks, and clear user-friendly error messages.
🎯 Panelized Insights Results split into panels: What She Said, What She Means, Smart Reply, and your Game Plan.

⚙️ How It Works

1
Type what she said
Enter her exact words — in English, Hindi, or Hinglish — into the text area on the main screen.
2
AI analyses the subtext
Your input is sent to the Manslator API, which forwards it to Groq's Llama 3 model with a carefully crafted system prompt designed to decode emotional intent.
3
Get decoded insight + the perfect reply
The app displays What She Said, What She Means, a Smart Reply, tone, confidence level, and a bite-sized coaching tip in four clean panels.
4
Deliver it with confidence
Copy the smart reply and send it — calm, steady, and with a smirk. 😎

🛠️ Tech Stack

Frontend HTML5, CSS3 (glassmorphism + CSS variables), Vanilla JavaScript — zero frameworks, zero dependencies.
Backend (Vercel) Serverless Node.js handler at api/manslator.js — runs on Vercel's Edge Network with Node 18 runtime.
Backend (PHP) PHP cURL fallback at manslator.php and api/manslator-php.php for traditional XAMPP / shared-hosting environments.
AI Model Groq API with Llama 3 family (openai/gpt-oss-120b by default) — configurable via environment variables.
Deployment Vercel (primary) with a vercel.json routing config, or any PHP-enabled web host as a fallback.

📡 API Reference

The frontend auto-discovers the right endpoint, trying each in order until one accepts the request:

Endpoint Runtime Use Case
POST /api/manslator Node.js (Vercel) Primary — used on Vercel deployments
POST /api/manslator-php.php PHP Fallback for PHP-enabled hosts
POST /manslator.php PHP Local XAMPP / legacy fallback

Request body:

{ "text": "what she said" }

Response body:

{ "reply": { "whatSheSaid": "...", "whatSheMeans": "...", "smartReply": "...", "tone": "playful | affectionate | bold | supportive | candid | reassuring", "confidence": "low | medium | high", "microAdvice": "..." } }

🚀 Setup & Deployment

1
Clone the repository
Fork or clone gauravbatule/ManslatorPRO to your local machine.
2
Configure environment variables
Copy .env.example to .env and set your Groq API key and optional model settings.
GROQ_API_KEY=your_groq_api_key_here GROQ_MODEL=openai/gpt-oss-120b GROQ_TEMPERATURE=1 GROQ_TOP_P=1 GROQ_MAX_COMPLETION_TOKENS=8192 GROQ_REASONING_EFFORT=medium
3
Deploy to Vercel (recommended)
Push to GitHub and import the repo into Vercel. Add your environment variables in the Project Settings → Environment Variables tab. The serverless function at api/manslator.js is picked up automatically.
4
Or run locally with XAMPP / PHP
Serve the repo root so that manslator.php is accessible at /manslator.php. Set GROQ_API_KEY as a server environment variable and open index.html in your browser.
